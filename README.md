# 👤 FaceVision — Real-Time OpenCV & Dlib Facial Recognition Web App

[![OpenCV](https://img.shields.io/badge/OpenCV-Computer%20Vision-green.svg)](https://opencv.org/)
[![Flask](https://img.shields.io/badge/Flask-Web%20Stream-black.svg)](https://flask.palletsprojects.com/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> **Real-time computer vision web application** streaming webcam video feeds for multi-person facial detection and 68-point facial landmark tracking using OpenCV and Dlib.

---

## 📌 Highlights

* **Low-Latency Video Stream**: Sub-30ms frame-by-frame MJPEG streaming via Flask.
* **Landmark Predictor**: Robust face orientation and landmark alignment.
